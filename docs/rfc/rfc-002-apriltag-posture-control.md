## RFC 002: 机器人姿态调整与硬件控制

**状态：** 草案

**修订日期：** 2026-04-02

## 1. 摘要
本 RFC 说明姿态调整模块如何接收上层处理后的目标信息，并驱动硬件控制或动作组完成“转向、接近、对正、稳定”。该模块与 AprilTag 读取并列存在，不直接依赖 AprilTag 检测 topic。

---

## 2. 目标与非目标
**目标：**
1. 定义姿态调整模块的输入与输出接口，保证可被上层调用。
2. 给出场景化动作策略，便于实现硬件控制或动作组调用。
3. 明确安全与降级规则，避免激烈动作。

**非目标：**
1. 不直接订阅或调用 AprilTag 检测结果。
2. 不负责全局路径规划与导航。
3. 不负责相机输入与感知计算。

---

## 3. 现状与痛点
姿态调整需要从上层获取“已经处理好的目标信息”，但目前缺少统一接口与动作规则，导致上层调用方式不一致。

---

## 4. 方案概览
通过一个可调用的 action 接口把上层目标信息传入姿态调整模块，由该模块直接控制硬件或动作组，完成对正与稳定。
数据流：上层处理 -> 姿态调整 action -> 硬件控制/动作组。

---

## 5. 关键接口
**Action 名称：** `posture_adjust`

**消息位置：** `ros2_ws/src/execution/posture_interfaces/action/PostureAdjust.action`

**输入（Goal）：**
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | int32 | 目标标签编号或目标点位编号 |
| `distance` | float32 | 与目标的直线距离（mm） |
| `center_offset_x` | float32 | 水平偏差，范围 `[-1, 1]` |
| `center_offset_y` | float32 | 垂直偏差，范围 `[-1, 1]` |
| `roll` | float32 | 翻滚角（deg，可选） |
| `yaw` | float32 | 偏航角（deg） |
| `pitch` | float32 | 俯仰角（deg） |
| `hamming` | int32 | 置信度指标（可选） |

**输出（Feedback）：**
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `state` | string | `accepted`, `running`, `paused` |
| `finished_stage` | int32 | 已完成阶段数 |
| `total_stage` | int32 | 总阶段数 |
| `error_code` | string | 失败或异常码（可选） |
| `message` | string | 补充说明（可选） |
| `timestamp` | Time | 状态时间戳 |

**输出（Result）：**
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `final_state` | string | `succeeded` / `failed` / `canceled` |
| `error_code` | string | 失败或异常码（可选） |
| `message` | string | 补充说明（可选） |

**动作策略（最小集合）：**
1. 目标丢失：左右小角度搜索。
2. 目标在左/右：优先小步转向，再判断。
3. 距离偏远：向前接近；距离过近：后退。
4. 到达工作距离：停止并保持稳定。

---

## 6. 数据/控制流
1. 上层模块处理目标并作为 action client 发起姿态调整。
2. 姿态调整模块执行动作组或直接控制硬件。
3. 姿态调整模块通过 action result 返回执行状态。

---

## 7. 风险与替代
1. **替代方案：** 直接由上层控制硬件。
   - **权衡：** 上层更灵活，但难以复用控制策略。
2. **替代方案：** 将姿态调整逻辑放在执行层动作任务流里。
   - **权衡：** 集中管理，但使执行层过重。
3. **风险：** action 接口不稳定会影响上层调用。

---

## 8. 验证计划
1. 上层可通过 action 成功驱动硬件动作。
2. 目标丢失/低置信度时不会触发激烈动作。
3. 达到工作距离后进入稳定状态。

---

## 9. 未决问题
1. `posture_adjust` 与 `task` 的关系：是独立 action 还是内嵌子流程。
2. 是否需要创建 `ros2_ws/src/execution/posture_interfaces` 包与 `PostureAdjust.action` 文件骨架。
